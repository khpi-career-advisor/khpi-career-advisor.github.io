## Як це працює

**1. Розроблення.** Виконується один раз, за потреби повторюється для доналаштування. Фахівці з психології та профорієнтації формулюють запитання. Модель GPT-4o-mini ранжує кожен варіант відповіді за чотирма напрямами: 4 означає найближчий напрям, 1 — найдальший, кожен ранг використовується рівно один раз. Відповідь моделі з порушеним форматом відкидається, і запит надсилається повторно. Оцінки $K$ незалежних запитів зводяться середнім геометричним:

$$r^{*}=\Big(\prod_{k=1}^{K} r^{(k)}\Big)^{1/K}$$

Отримані ранги записуються у `data.js` застосунку.

**2. Використання.** Обчислення виконуються в браузері, мовна модель при цьому не викликається. Для кожного напряму $d$ підсумовуються ранги обраних відповідей $S_d$, після чого сума нормується:

$$P_d=\frac{S_d-S_d^{\min}}{S_d^{\max}-S_d^{\min}}\cdot 100\%$$

$S_d^{\min}$ і $S_d^{\max}$ — найменша й найбільша сума, яку можна набрати для напряму. У тесті «Так/Ні» $S_d^{\min}=0$, бо відповідь «Ні» балів не додає. Кожен напрям має власну шкалу, тому сума відсотків не дорівнює 100 %. Однакові відповіді завжди дають однаковий результат.

**Розширення до ансамблю.** Методика розрахована на будь-яку кількість експертів $K$. Ранги чат-бота зараз отримано одним запитом ($K = 1$). Повторні запити або оцінки інших мовних моделей підвищують надійність рангів. Щоб їх додати, достатньо оновити ранги в `data.js`, код змінювати не потрібно.

## Технічна основа

- HTML, CSS і JavaScript без бібліотек, збирання та сервера.
- Немає бази даних, cookie, localStorage та аналітики. Відповіді нікуди не надсилаються.
- Запитання, ранги, напрями й посилання зберігаються в `data.js` кожного сервісу.
- Хостинг на GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
- Для локального запуску достатньо відкрити `index.html`.

### Цей репозиторій: лендинг проєкту

```
index.html   розмітка сторінки
style.css    стилі й адаптивна верстка
app.js       анімації, відеоплеєр, вкладки, лайтбокс
img/         логотип, скриншоти, QR-коди, фото команди та впровадження
fonts/       Geist і Geist Mono (SIL Open Font License)
```

Відео з YouTube вантажиться лише після натискання кнопки відтворення, через `youtube-nocookie.com`. Фото команди лежать у `img/team/` за прізвищами: щоб замінити фото, достатньо підкласти новий файл з тим самим ім'ям.
