# Тест з профорієнтації НТУ «ХПІ»

Статичний сайт на HTML, CSS і JavaScript без бібліотек, збірки та сервера.
Відповіді ніде не зберігаються і нікуди не надсилаються: результат обчислюється в браузері.

## Файли

- `index.html` — розмітка трьох екранів: привітання, запитання, результат
- `style.css` — стилі
- `app.js` — логіка тесту та підбір спеціальностей
- `data.js` — 25 запитань, 51 спеціальність і ваги зв'язків між ними
- `logo.png`, `questions/`, `fonts/` — зображення та шрифти Geist

## Запуск

Відкрийте `index.html` у браузері (працює і без сервера) або завантажте папку на будь-який хостинг.

## GitHub Pages

1. Завантажте вміст папки в корінь репозиторію.
2. Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.

## Як підбираються спеціальності

Кожна відповідь «Так» додає ваги запитання (1–3) пов'язаним спеціальностям у `data.js`.
Підсумковий бал: `набрані · √(набрані / максимально можливі)`. Дві спеціальності з найвищим балом
і одна-дві риси, що на них найбільше вплинули, складаються в текст результату.
Щоб змінити рекомендації, редагуйте `weights` у `data.js`; назви мають збігатися зі списком `SPECIALTIES`.
