# Профорієнтаційний чат-бот НТУ «ХПІ» (статична версія)

Статичний сайт на чистих HTML, CSS і JavaScript, без зовнішніх залежностей, збирання та сервера. Сайт не збирає й не зберігає жодних даних: усе обчислюється в браузері, а після перезавантаження сторінки розмова починається з початку.

## Як працює

1. Користувач натискає «Привіт, я хочу пройти тестування!».
2. Бот ставить 5 питань з оригінального сценарію. На кожне можна обрати до 3 готових варіантів.
3. Варіант «Не знаю» відкриває навідне питання з простішими варіантами (у ньому можна натиснути «Пропустити питання»).
4. Кожен варіант додає до портрета користувача ознаки з вагою 1–3 (математика, IT, енергетика, комунікація тощо).
5. Портрет порівнюється з 24 портретами професій за косинусною близькістю.
6. Результат: опис сильних сторін, спеціальності НТУ «ХПІ», три найближчі професії з поясненням і порадою. Можна показати ще 3 варіанти або пройти тест знову.

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | розмітка сторінки |
| `style.css` | стилі (кольори й розміри перенесено з оригіналу) |
| `data.js` | питання, варіанти відповідей, ваги ознак, професії та коди спеціальностей |
| `app.js` | логіка діалогу та підбору професій |
| `assets/` | логотип, шрифт Geist, зображення для соцмереж |

Щоб змінити питання, професії або ваги, достатньо відредагувати `data.js`.

## Розгортання на GitHub Pages

1. Завантажте вміст цієї папки в корінь репозиторію (файл `.nojekyll` теж).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. За хвилину сайт буде доступний за адресою `https://<користувач>.github.io/<репозиторій>/`.

Усі шляхи відносні, тому сайт працює і в підпапці, і локально: достатньо відкрити `index.html` у браузері.

## Відмінності від оригіналу

- Замість вільного введення тексту користувач обирає готові варіанти відповідей.
- Замість мовної моделі OpenAI рекомендації формує детермінований алгоритм зіставлення ознак.
- Прибрано авторизацію, базу даних Firebase, збереження та експорт чатів, а також шосте питання (вік, стать, e-mail), бо воно потрібне було лише для статистики.

Оригінальний проєкт: дипломна робота Ксенії Хорєшко, НТУ «ХПІ».
